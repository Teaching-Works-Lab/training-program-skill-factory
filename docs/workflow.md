# 工作流

1. 记录来源文件、版本标识、授权的匿名化与发布边界。
2. 用 `scaffold` 建立候选目录；提取表格和矩阵时保留页码、符号和 `extracted`/`needs_review` 状态。
3. 对有歧义的单元格逐项视觉复核；不要用相邻单元格、模糊字形或旧 JSON 代替证据。
4. 运行 `scripts/curriculum.py validate <program.json>`。修复结构错误或保留未知项；警告是诊断，不是质量、达成或发布结论。
5. 用 `diff` 比较新旧版本。保留旧 JSON，新版本独立存放，并把冲突列为待处理或有来源支持的变更。
6. 用 `generate_skill.py` 生成独立专业 Skill，并在生成目录运行一次 `validate`。
7. 仅在获准范围内匿名化；记录实测时长、瓶颈和后续假设。

每个阶段都保留“官方直接”“派生”和“未解决”三个边界。课程大纲中没有来源的字段保留 `待编制`。
