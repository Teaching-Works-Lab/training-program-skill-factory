# 复用与提速

提速顺序是：先复用已有资产，再把变化值作为参数输入；只有现有接口无法表达可复现需求时，才新增模板或脚本。

## 可复用资产

| 资产 | 直接复用场景 | 不应写死的内容 |
| --- | --- | --- |
| `templates/syllabus-skill/` | 生成每个专业的独立 Skill 骨架和最小运行时 | 专业名、学校身份、课程事实和本机路径 |
| `scripts/generate_skill.py` | 校验 JSON、复制模板、替换 Skill 身份并写生成清单 | 输入文件、输出目录、Skill 名、显示名和工厂提交 |
| `scripts/curriculum.py` | scaffold、矩阵候选、校验、查询、渲染和版本 diff | 每次来源、课程、页码和指标点参数 |
| `references/program.schema.json` | 不同专业使用同一稳定数据合同 | 某一专业的具体课程或关系 |
| `docs/` | 复用工作流、风险、经验和性能记录方式 | 未经验证的一次性 workaround |
| `tests/fixtures/` | 测试接口和生成过程 | 真实专业答案或发布数据 |

先运行现有命令的 `--help` 并检查模板；不要在项目目录重新生成已经存在的同类脚本。

## 参数化调用

把每次变化的值留在命令行或本次数据文件中，不复制进 Python 源码：

```powershell
$programPath = "<program.json>"
$outputDir = "<output-dir>"
$skillName = "<lowercase-skill-name>"
$displayName = "<display-name>"
$factoryCommit = git rev-parse HEAD

py -3.12 scripts/generate_skill.py `
  $programPath $outputDir `
  --skill-name $skillName `
  --display-name $displayName `
  --factory-commit $factoryCommit
```

课程名称、代码、学分、学时、关系与 provenance 属于 `program.json`；它们不是生成器配置，更不能硬编码为 Python 常量。

## 何时新增资产

- 稳定输出骨架在多个专业重复出现：更新已有模板。
- 同一确定性步骤反复手工执行，且输入、输出和失败条件已经明确：扩展现有 CLI 或增加小脚本及对应测试。
- 数据结构跨专业稳定：更新 Schema，并检查既有数据兼容性。
- 只出现一次、原因未隔离或仍需人工判断：保留在运行记录，不新增通用代码。

不要仅为少输几个参数增加配置框架。现有 CLI 可以清楚表达本次输入时，直接调用它更快，也更容易追踪。

## 提速机制

| 做法 | 为什么可能更快 | 证据边界 |
| --- | --- | --- |
| 模板复制 | 不重复生成目录、运行时和元数据结构 | 模板摘要只证明复制来源，不证明专业数据正确 |
| 命令行参数 | 同一 Python 实现适用于不同专业和目录 | 参数仍需按本次来源填写 |
| Schema 与 CLI 校验 | 机械问题一次检查、结果可复现 | 无错误不等于视觉审核完成 |
| 新旧版本 diff | 优先定位新增、变化和冲突 | diff 不能自动证明 PDF 版面未变化 |
| 复用已有审核决定 | 避免对同一来源、同一版本、同一事实重复执行相同审核 | 来源或事实变化后必须建立对应的新证据 |

速度结论需在相同或可比较的范围下记录实际耗时。没有前后对照时，只说明复用机制和本次耗时，不宣称普遍提速比例。

## 最小充分审核

每项审核都对应一个具体风险：

- 新增、变化、冲突、校验错误、`needs_review`、复杂版面和公开边界需要处理；
- 已有唯一审核决定，且能确认来源、版本、页码和事实均未变化时，不重复相同审核；
- 无法确认是否未变时，保持待复核，不用旧决定自动升格；
- 首次要标为 `visually_verified` 的事实必须有本次可追踪证据；
- 一个确定性检查已经覆盖某项风险并通过后，不再为同一风险堆叠同类检查。

停止条件是：结构错误为零；目标范围内的新变化和歧义已处理；未解决项明确保留；发布边界已检查；生成结果能独立校验。随后报告实际覆盖范围，不继续增加没有风险依据的审核轮次。

允许断言“结构校验无错误”“列明的页面/单元格已视觉复核”“生成 Skill 可独立校验”。不要从这些结果扩展为“全面审核无问题”、培养质量、学习成效或未检查范围的正确性结论。
