# 常见风险

| 风险 | 处理 |
| --- | --- |
| 旧 JSON 与新来源冲突 | 新建版本并输出 diff；不覆盖旧文件。 |
| 提取项被自动标为已核验 | 保持 `extracted` 或 `needs_review`，等待视觉审核。 |
| 把派生追踪当官方矩阵 | 保留 `via` 与 `derived_transitive` 标签。 |
| 未知课时参与汇总 | 保留 `null`；不要转换为 `0`。 |
| 将课程组关系复制给每门成员课 | 仅保留原始课程组关系，除非来源逐门给出。 |
| 未提供课程目标仍生成完整大纲 | 相关字段写为 `待编制`。 |
| 输出含机构、机器路径或未授权原件 | 在发布前按授权范围匿名化并检查输出。 |
| 把 MarkItDown 输出当作原 PDF 的完整事实副本 | Markdown 只作候选；复杂表格、矩阵、双栏、公式和异常页回到原 PDF 复核。 |
| 用 Pandoc 导出成功证明内容正确 | Pandoc 只做格式转换；单独检查目标文件，事实仍以 Markdown 内容及其来源为准。 |
| 一次故障被写成通用规则 | 先标为本次观察或待验证；只有机制明确或跨运行复现后才泛化。 |
| 新经验与旧文档冲突时直接覆盖 | 并列记录证据与适用条件，确认取代或收窄关系后再更新规则。 |
