# 性能记录

## 已测量

- 一次本地 Markdown 转换记录为 8,907 ms。
- 同一次运行的源文件渲染为 26 页；表格和矩阵的人工视觉复核覆盖跨多页单元格，构成了主要人工等待环节。

这些值是单次运行记录，受硬件、文件复杂度、OCR/渲染工具和审核范围影响；它们不是服务等级或通用速度承诺。

## 已观察到的瓶颈

- 表格合并单元格、跨页课程行和矩阵行/列对齐需要逐页确认。
- 版本差异必须在新候选完成后比较，不能通过跳过复核缩短流程。

## 待验证的速度假设

- 先用 scaffold 记录来源和候选位置，可能减少后续回溯定位时间。
- 将视觉审核按页和唯一决定 ID 组织，可能减少重复审核。

上述假设尚未通过对照测量；不得据此降低验证门槛或承诺耗时。
